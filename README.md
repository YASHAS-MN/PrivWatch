## Excluded Files

The following files and directories are not included in this repository for security, size, or privacy reasons:

- **Sensitive keys**: Any API keys, credentials, or sensitive configuration files are excluded. You will need to obtain or generate these separately.
- **Raw video datasets**: The `data/raw_videos/` directory containing raw video files is not included due to size and privacy concerns. You will need to acquire the datasets separately (see [link or instructions if available]).
- **Virtual environments**: `privwatch_env/`, `priv2_env/`, and `Priv1.0/privwatch_env/`, `Priv2.0/env/` are excluded. Create your own virtual environment.
- **Large model files**: If certain model files are too large, they may be excluded. Download them separately if needed.
